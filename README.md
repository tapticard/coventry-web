# Coventry — Concepto web

Concepto de sitio web para Coventry (electrodomésticos, República Dominicana). HTML y CSS sin frameworks, con una hoja de estilos compartida.

## Páginas
- `index.html` — Inicio
- `productos.html` — Catálogo con filtros
- `air-fryer-xl.html` — Ficha de producto modelo
- `quienes-somos.html` — Historia, misión, visión y valores
- `distribuidores.html` — Cómo ser distribuidor + solicitud
- `contacto.html` — Contacto de clientes y "¿Dónde comprar?"

## Estructura
- `assets/css/styles.css` — estilos compartidos (tokens de marca al inicio)
- `assets/js/main.js` — menú móvil, filtros, galería y formularios
- `assets/logos/` — logos oficiales
